# Metro Rush — Endless Runner

Jogo de corrida infinita para navegador, independente e original, criado com HTML, CSS e JavaScript puro.

## Executar
Abra `index.html` em um navegador moderno. Não precisa instalar dependências nem iniciar servidor.

## Controles
- **A / ←**: pista esquerda
- **D / →**: pista direita
- **W / ↑ / Espaço**: pular
- **S / ↓**: deslizar
- **P / Esc**: pausar
- **Celular**: botões na tela ou gestos de deslizar

## Recursos
- Três pistas, obstáculos, trens estilizados e moedas
- Pulo e deslize com janelas de tempo
- Power-ups: ímã, escudo e moedas em dobro
- Velocidade progressiva, pontuação e recorde local
- Layout adaptável e efeitos sonoros sintetizados
- Gráficos procedurais, sem arquivos externos

## Créditos e propriedade intelectual
Projeto independente do gênero endless runner. Não é afiliado à SYBO Games e não inclui personagens, marcas, músicas, mapas ou arquivos proprietários de Subway Surfers.

## Tecnologia
Canvas 2D, Web APIs e `requestAnimationFrame`. O recorde é salvo no `localStorage` do navegador.
